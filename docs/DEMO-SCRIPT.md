# Demo script (target < 5 minutes)

Lead with the person, not the tech (IDEA risk #7). Persona names are illustrative; real student stories only with consent.

**Act 0 — Hook (30s).** Sita, final-year CS student. Family about to pay Rs 30 lakh for a Japan consultancy. Job posts say "not for Nepal".

**Act 1 — The bond (60s).** Voucher (alumnus abroad) reads Sita's triage report → backs her with $1,000. Dashboard shows the bond.

**Act 2 — The contract (60s).** Client creates a 3-milestone commitment, funds salary + 3% premium + 1% fee. Milestone 1 is a GitHub task.

**Act 3 — Delivery (60s).** PR merged → oracle releases → mock partner pays NPR → switch to the **family page**: NPR landed (MOCK badge). Open Sita's **public profile**: Paid Delivery Record, verifiable on explorer. Voucher sees premium.

**Act 4 — When it fails (45s).** Milestone 2 not delivered → client files claim → panel of 3 votes Upheld → bond pays client. Voucher dashboard shows the loss. Sita's profile shows nothing negative.

**Act 5 — Why it matters (30s).** No crypto touches Nepal. Measurement plan (lottery + control). Results of the Week-0 gates (real numbers only).

Must be on screen at some point: devnet label, MOCK labels, explorer links.
